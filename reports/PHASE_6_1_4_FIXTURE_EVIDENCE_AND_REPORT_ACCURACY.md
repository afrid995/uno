## 4. Competing-Opponent Search-Order Test Scenario & Evidence

### Test Scenario Design
- **Players:** 4 players: Alice (`p1`, index 0), Bob (`p2`, index 1), Charlie (`p3`, index 2), Dave (`p4`, index 3).
- **Physical Cards:** In the verified 168-card No Mercy deck generated by `NoMercyDeckFactory`, there are exactly 2 copies of `skip_everyone` in `blue`:
  - `cardForBobId`: `nm_blue_skip_everyone_copy_1`
  - `cardForCharlieId`: `nm_blue_skip_everyone_copy_2`
  Both cards share identical value (`skip_everyone`), color (`blue`), and type (`action`), but possess distinct physical IDs. No other cards in the deck match this face.
- **State Arrangement:**
  - `swapTwoCardsInState` places `cardForBobId` into Bob's hand at index 0.
  - `swapTwoCardsInState` places `cardForCharlieId` into Charlie's hand at index 0.
  - Total card conservation (168 cards) and ID uniqueness strictly validated via `assertValidNoMercyGameState`.
- **Precondition Assertions:**
  - Target player Alice holds no matching cards (`arrangedState.players[0].hand.some(predicate) === false`).
  - Draw pile holds no matching cards (`arrangedState.drawPile.some(predicate) === false`).
  - Discard pile holds no matching cards (`arrangedState.discardPile.some(predicate) === false`).
  - Dave holds no matching cards (`arrangedState.players[3].hand.some(predicate) === false`).
  - Both Bob (index 1) and Charlie (index 2) hold cards matching `predicate`.
  - `cardForBob.id !== cardForCharlie.id`.
- **Execution & Invariant Assertions:**
  - `swapCardIntoHand(arrangedState, 'p1', predicate)` evaluates opponents in player-array iteration order.
  - Bob (`p2`, index 1) is evaluated before Charlie (`p3`, index 2).
  - Alice receives Bob's card (`injectedCard.id === cardForBobId`).
  - Alice's evicted card (`aliceEvictedCard`) is transferred to Bob's hand at index 0.
  - Charlie's hand is completely untouched (`nextState.players[2].hand.map(c => c.id)` equals `charlieInitialHandSnapshot`).
  - Dave's hand is completely untouched.
  - Hand sizes remain invariant across all 4 players ($7 \to 7$).
  - Full game state invariant `assertValidNoMercyGameState` confirms all 168 cards are present with unique IDs.

## 5. Failure Immutability Test Evidence

All three failure cases in `packages/game-engine/tests/no-mercy.fixture.test.ts` now execute byte-for-byte serialization comparisons:

```typescript
// 1. Missing Card ID
const stateSnapshot = JSON.stringify(state);
expect(() =>
  NoMercyFixtureBuilder.swapCardIntoHand(state, 'p1', (c) => c.id === 'non_existent_card_999')
).toThrow('No matching card found in existing game inventory to swap.');
expect(JSON.stringify(state)).toBe(stateSnapshot);

// 2. Unknown Target Player ID
const stateSnapshot = JSON.stringify(state);
expect(() =>
  NoMercyFixtureBuilder.swapCardIntoHand(state, 'unknown_player', () => true)
).toThrow('Player unknown_player not found in state.');
expect(JSON.stringify(state)).toBe(stateSnapshot);

// 3. Empty Target Hand
const stateSnapshot = JSON.stringify(emptyHandState);
expect(() =>
  NoMercyFixtureBuilder.swapCardIntoHand(emptyHandState, 'p1', () => true)
).toThrow('Player p1 has no cards to swap.');
expect(JSON.stringify(emptyHandState)).toBe(stateSnapshot);
```
